# Banco de Dados - RepairSim

## Como utilizar

1. Abra o MySQL Workbench.
2. Abra o arquivo repairsim.sql. (importante: foi exportado as informações com base no banco de Marko no NoteBook)
3. Execute todo o script.
4. O banco repairsim1 será criado automaticamente.

Após isso, configure o arquivo .env do Backend.

NOTA: deve se instalar  npm install dotenv  e  npm install express mysql2 cors dotenv em seus computadores.
